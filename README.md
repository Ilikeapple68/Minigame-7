# MG7
## Devlog

While coding the TreeOfBirds script. The arrays are used to track all the birds that exists on the tree, and the Vector3.Distance are used to track the distance between transform a and transform b. In my script the arrays are used in a foreach loop, it loops through all the birds in array, then plug in the transform of all birds and player to calculate the distance using Vector3.Distance. Last, I used of if statement to activate the bird object if the distance calculated is less than the InteractionDistance variable.
